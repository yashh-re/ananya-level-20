# Agent Ananya // Level 20

An interactive, cinematic birthday reveal built as a classified S.H.I.E.L.D.
mission dossier. The experience unveils Ananya's 20th-birthday gift: an
advance preview of *Avengers: Doomsday* on December 17, 2026, with her ticket
and round-trip travel covered.

## Experience

- Secure identity-verification entry screen
- Personalized Level 20 agent dossier
- Doomsday mission briefing and threat scan
- Collectible-style admission ticket
- Animated round-trip extraction plan
- Live December 17 countdown
- Mission acceptance celebration
- Responsive desktop and mobile layouts

## Local development

```bash
npm install
npm run dev
npm run build
```
